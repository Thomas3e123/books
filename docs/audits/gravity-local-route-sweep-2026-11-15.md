# Gravity local route sweep — 2026-11-15

## Scope

Scanned HTML pages under `site/` for local `href`, `src`, and `action` references. The source-level sweep inspected 7,974 references.

## Review of references not represented as ordinary files

The first pass flagged expected runtime routes and generated paths as missing files. Source configuration confirms:

- `/.netlify/images?...` URLs are Netlify Image CDN transforms, not files in the repository.
- `/gravity-report/:slug`, `/gravity-report/articles.json`, `/gravity-report/feed.xml`, `/gravity-report/sitemap.xml`, and `/gravity-report/reader-text` are served by the Gravity Report function. The function returns published article pages and rejects unpublished issues.
- `/e` and `/e/*` route to the SOP Foundry employee access page in `site/_redirects`.
- `site/handbook-creator/app.js` and `app.css` are intentionally generated by `scripts/build-handbook.mjs` during the production build and are git-ignored generated outputs.

## Result and limits

No confirmed broken local destination was identified in this source sweep. This is not a hosted HTTP crawl, a click-through browser audit, or a mobile/device verification. It does not certify that redirects or generated assets are correctly published in the current production deploy.
