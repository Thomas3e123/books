- **Week 1.** Verify Search Console. Export the last available 28 days of Web Search by query and landing page. Keep branded terms (Gravity, Thomas Butler, Thomas Monroe Books) separate from restaurant-problem searches. Record US mobile and desktop separately where volume allows. - **Weeks 2–4.** Ship the archive links and three page improvements in a measured batch. Add relevant links from already published stories and guides. Keep article authorship clear. Use the pilot, with permission, to collect one documented operator example. Share the most relevant finished resource with a training partner or restaurant association only when there is genuine editorial interest.
- **Days 30, 60 and 90.** Compare equal 28-day periods. Track nonbranded impressions, clicks, click-through rate, average position for the same query/page pairs, and useful actions per organic landing. Confirm each site's analytics events exist before treating an action as measured. Exclude tagged test sessions where possible. If impressions grow without clicks, compare the page title and promise to the actual query. If clicks grow without tool use, inspect the first screen and access path. If pages get no impressions, check indexing first. Avoid ranking commitments based on small samples.
