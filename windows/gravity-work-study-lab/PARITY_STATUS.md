# Gravity Work Study Lab — Windows Parity Status

Controlled source status: 2026-10-17

## Current parity model

The Windows beta now packages the same Work Study expert JavaScript/CSS source used by the website. The Windows build runs `sync-expert-stack.cjs`, reads the website installer as the authoritative script list, copies the current Work Study sources into the Windows package, and refuses to build if required expert layers through v61 are missing.

## Verified expert stack included in Windows

- Guided / Assisted / Independent / Passive study modes and first-time-user guidance.
- Timer-integrity protection and natural-language Clock Control.
- Production-safe multi-run timing and run comparability.
- Process/recipe observation mapping. TXT/MD/CSV work locally; DOCX extraction uses the Thomas Monroe Books hosted reader and therefore requires internet access.
- Parallel machine/process time and labor occupancy.
- Verified segment references and practical restaurant timing units.
- Standard-minute validity, fixed/variable scaling, verified-baseline provenance, and revalidation holds.
- Staffing allowance control with no invented universal allowance.
- Observer agreement, proficiency representativeness, observation-effect controls, precision, demand coverage, shared setup, crew labor, yield/waste protection, Work Sampling, queue/recovery, incomplete-cycle protection, short-element measurement adequacy, shift-position representativeness, and sequence-dependent changeovers.
- Ergonomic/physical-demand screening, learning-curve controls, operating-context representativeness, and sustainable-pace validation.
- Gravity Expert Triage v61 for blocker-first next-action guidance.
- Complete `.gravity-study.json` evidence packaging including study-specific expert sidecars.
- Premium gold-trimmed Work Study visual package.

## Persistence and portability

The synchronized expert engine uses the same local-first browser storage model as the website inside Electron. Complete evidence packages can be exported/imported for portability. The older Electron IPC study store remains available to the application shell for compatibility, but the synchronized expert engine is the source of truth for current studies.

## Not claimed

- Automatic hosted cross-device synchronization is not yet implemented.
- The Windows beta is not digitally code-signed.
- DOCX extraction requires internet access to the Thomas Monroe Books process-file function; the rest of the expert study engine is packaged locally.

## Parity rule going forward

Do not hand-port future Work Study expert layers into a separate Windows reasoning engine. Add them to the website master source, update the controlled website installer, and let the Windows synchronization/build gate package the same source. This keeps one Gravity Work Study brain across web and Windows.
