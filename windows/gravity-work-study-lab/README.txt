ONE GRAVITY BRAIN
The Windows build does not maintain a separate copy of Gravity's expert reasoning. Before packaging, sync-expert-stack.cjs reads the controlled website Work Study source, copies the same expert JavaScript and CSS into the Windows package, and fails the build if required expert, Guided-stability, or evidence layers are missing.

LOCAL DATA
The expert engine remains local-first. Windows also mirrors the complete evidence package into its application data folder using atomic JSON writes so the base study and study-specific expert sidecars remain together.

DOCX / WRITTEN PROCESS FILES
TXT, MD, CSV, and pasted directions are handled locally. DOCX text extraction uses the Thomas Monroe Books hosted process-file reader through the Electron main process and therefore requires internet access for that specific action.

GUIDED VOICE
Guided uses Gravity's hosted Cedar neural voice. Click Guided once and wait for Gravity to join the study. Do not repeatedly click Guided while the expert panels and voice initialize.

CURRENT LIMITATIONS
- This is a beta build.
- Automatic hosted cross-device synchronization is not yet implemented.
- The beta is not digitally code-signed and Windows SmartScreen may warn during installation.
- The Windows package currently uses the default Electron application icon.
- Hosted Cedar voice and DOCX extraction require internet access.

BUILD
Run BUILD_WINDOWS.cmd on a Windows computer with Node.js 22 or later.
The builder installs dependencies, synchronizes and verifies the full expert stack, then produces installer/ZIP output in dist.

THE CODE
Gravity records, calculates, organizes, verifies, connects, preserves, and presents proven knowledge while keeping measured evidence separate from interpretation. Quality and safety remain above speed.
