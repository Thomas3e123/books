Before using a Windows Beta or Preview

1. Choose the EXE for an installer, or download the ZIP, extract it, and run the portable program EXE. New portable-preview ZIPs do not contain a separate INSTALL file. Earlier October 12 Betas may use different installation packages; follow their included instructions. 2. Save an independent backup of existing restaurant data before upgrading. Older editions may use separate storage and may not migrate automatically. 3. These previews are unsigned. Only use linked downloads, run a complete sample workflow, and verify printing, scanning, and backup/restore before live use. 4. Continue using the web edition whenever it better fits your workflow.
