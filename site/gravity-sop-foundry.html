Manager guidance: Gravity Signals
Optional manager decision support

What Gravity Signals is—and why it stays manager-only.

Gravity Signals can help a manager notice patterns that may deserve review, but it never decides what those patterns mean. A Gravity Signal is an indicator, not a conclusion.

Examples of useful indicators

Signals may help a manager notice several employees struggling with the same knowledge-check material, repeated questions or error reports around one procedure, a possible documentation gap, incomplete follow-up requirements, or a possible cross-training opportunity.

What the manager does next

The manager checks the actual SOP, training, workflow, equipment, timing, and employee circumstances before deciding whether anything needs to change. The same indicator can have several possible explanations.

Why employees do not see Signals

Employees should be free to reread an SOP, ask questions, and explore learning material naturally. Showing the internal Signal logic could cause employees to avoid useful learning behavior—or deliberately try to create a Signal—which would make the information less reliable.

Restaurant-controlled and optional

The restaurant chooses whether to enable Gravity Signals. Managers can turn the feature off completely, disable categories, or disable individual Signal types. Turning Signals off stops manager-side Signal calculation while normal training, acknowledgments, quiz records, and employee questions continue to work.

More about Foundry controls
Built to compete as an SOP creation system — not a generic project board

Useful controls without unnecessary management software clutter.

Modern SOP tools commonly add owner, status, priority, review frequency, due/review dates, approval stages and version history. Gravity SOP Foundry includes those controls, then adds restaurant-specific Gravity features: 525 controlled source procedures, department and specialty packs, master comparison, blank SOP creation, local restaurant defaults, readiness checks, binder building and self-print output. The source library uses the current controlled 525-SOP library.
