Restaurant Improvement Pilot

Work on one restaurant problem at a time.

This pilot is for people new to Gravity. You do not need to know the tools yet. Pick one starting path below: test a Gravity tool, or work on one recurring problem in a restaurant you manage. The room will tell you what to do next.

Start here

What is going on, and what do I do?

Gravity is asking for help checking its tools and learning whether small restaurant improvements work. You are not expected to know Gravity before you begin.

  1. Choose one path below: test a Gravity tool, or try one small change for a recurring problem at a restaurant you manage.
  2. Create your private space: enter your name, email, and role. The room creates a private return link. Copy and keep that link so you can come back.
  3. Follow the matching steps: for a tool test, open one guide and try one tool with made-up sample information. For a restaurant improvement, set a starting measure in your own records and build a 30-day or 60-day plan.
  4. Save what happened: report what worked, what did not, or what stopped you. “No change” and “I got stuck” are useful answers.

Not an owner or manager? Choose a tool test. You do not have to change a restaurant. Never enter private employee, guest, payroll, payment, password, or exact financial information.

Step-by-step test protocols

This catalog covers tools linked from Gravity’s current public pages. Choose one guide, follow its steps, and record Pass, Fail, Blocked, Not tested, or Not applicable for each case. If a listed public link fails, report the failure; unlisted tools are outside this catalog. Use fictional restaurant data. If an expected result is unclear, mark it Blocked or Not tested and explain what needs clarification.

Do not enter real employee, guest, payroll, payment, or exact financial records. If a test fails, save the report and use Report a problem to describe the failure.
