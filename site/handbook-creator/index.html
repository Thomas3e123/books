Handbook Creator — User guide

Build your handbook, choose its design, review it, and download your files. Open this guide at any time; closing it returns you to your work.

1. Save your work — understand the three options
  • Save / automatic saving: keeps your answers in this browser on this device. It does not create a file or ask for a folder. Wait for Saved on this device before closing.
  • Save project backup: downloads a .gravityhandbook file containing your answers, skips, interview choices, and design. Keep this file so you can reopen and continue editing in the Creator.
  • Download PDF / Download editable Word: creates a readable handbook for reviewing, printing, or editing in Word. These files cannot be imported as Creator project backups. Keep the backup as well.

Make a backup before you stop

  1. Check that the correct handbook is selected under Handbook projects.
  2. Wait for the saved indicator, then click Save project backup.
  3. If a save window opens, choose your folder and save. Otherwise check your browser’s Downloads list or Downloads folder.
  4. Keep a dated copy after each work session, for example River-Handbook-2026-11-01.gravityhandbook. Renaming the file is fine; keep its extension.

Projects are not synced to the cloud. Another device, another browser, private browsing, or clearing browser data may leave you without the locally saved project. A downloaded backup lets you restore it.

Choose where downloaded files go

Folder selection is controlled by your browser, not the Creator’s Save button. In Chrome on a computer, open ⋮ → Settings → Downloads and enable Ask where to save each file before downloading. This applies to backups, PDFs, and Word downloads. Chrome download instructions.

2. Start a new handbook without losing the first
  1. Finish reviewing the current handbook and download its PDF or Word file if needed.
  2. Click Save project backup and keep that backup.
  3. Click New handbook near the top of the left panel. This creates a separate blank project; it does not erase the previous one.
  4. Enter the new restaurant or company name. The project title comes from that answer; until then it appears as Untitled handbook.
  5. Choose the interview level and answer Business fit for the new business. New projects start on Basic.

Use the Handbook projects dropdown to return to an earlier handbook. Check the selected name before making changes. To reuse an existing handbook as a starting point, select it and click Duplicate instead of New handbook, then change the name and review the copied answers.

3. Reopen a backup or move to another device
  1. Locate your downloaded .gravityhandbook file. If moving devices, transfer that file to the other device.
  2. Open the Creator and click Open project backup.
  3. Select the backup file. It opens as a separate project with “restored” in its title; existing projects stay intact.
  4. Check the answers and design, continue editing, and save a fresh backup afterward.

Choose the Creator backup file, not the PDF or Word export. Importing the same backup again creates another restored copy.

4. Choose the interview and business topics

Basic covers core everyday policies. Extended adds operating detail. Full shows all 174 questions.

Business fit controls tips, alcohol, employees under 18, and specialty topics in Basic and Extended. Choose Yes, No, or Not sure. Not sure keeps topics visible for review. For specialized operations, select each applicable topic. Full always shows all questions.

Counts adjust to your choices. Switching levels or Business fit does not delete existing answers or remove their wording from your handbook. Use Skip Altogether on a question to exclude its wording.

5. Answer, save, skip, and track progress
  1. Work through up to four questions per set. Type your own wording; it saves automatically.
  2. For an empty text answer, Use example & save adopts the displayed example. Edit it to match your business.
  3. Save on an answered question keeps the answer and advances to the next question in the set. Only the last question offers Save & continue to move to the next set.
  4. If any question in that set is unanswered or skipped, continuing asks for confirmation. Cancel keeps you in the set.
  5. Skip for Now postpones a question. Skip Altogether excludes its wording. Revisit either under Review & postponed questions and choose Restore.

The answered count shows nonempty answers in your current interview. Business-fit selections do not count as handbook answers. Editing an already answered question does not increase the count. Changing the level or topics can change the count because it changes the questions being counted.

Use remaining examples & finish fills unanswered text questions in your current interview and opens review. It preserves existing answers and deliberate skips and does not add a logo. Review the adopted examples before use.

6. Choose the design and review the handbook
  1. Open Color, style & edition.
  2. Choose a template or Create your own style. Custom choices include page background, fonts, colors, borders, and divider lines.
  3. Enter the edition name and optional effective date. Add or change the logo if desired.
  4. Select Preview only to view the handbook without downloading. Use Change style to return to design or Return to interview to edit answers.

Review & postponed questions provides search, unanswered and skipped topics, change history, and writing checks. Browser spellcheck is available; the built-in writing review checks spacing and repeated words, not full grammar or AI rewriting. Read every policy for accuracy. Exports remain drafts for owner and appropriate legal review.

7. Download and print the finished handbook
  1. Click Preview & download. This opens the preview and download choices; it does not download automatically.
  2. Choose Download PDF for a consistent page layout, or Download editable Word to edit in Word.
  3. Find the file in the folder you selected or your Downloads folder. If the download did not start, use the file link in the message at the top.
  4. To print, choose Print-ready PDF, open the downloaded PDF, and use Print. Use Actual size for US Letter paper.
  5. Save a separate project backup before closing or starting the next handbook.

Word may reflow differently from the PDF. Changes made in Word do not update your Creator project. Make changes in the Creator and download again when you want both versions to match.

8. If something does not save or download
  • NOT SAVED: download a project backup immediately and keep the page open until you have it.
  • Changed in another window: save a backup of the current work before reloading. Avoid editing the same project in two tabs at once.
  • Cannot find a file: check the browser’s Downloads list and download settings. Save inside the interview does not create a file.
  • Blank project list on another device: use Open project backup. Local projects do not automatically travel between devices.
