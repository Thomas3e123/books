Room PIN settings

Only Build Room access can change either PIN. Use different PINs to keep employee viewing separate from editing access.

Changing a PIN locks existing sessions for that room. When you change the Build Room PIN, this session stays open; other Build Room sessions must unlock again. Share the new Employee Library PIN directly with employees. Never print PINs on posters or QR codes. Hosted Employee Access cannot use the default 0000 PIN; a connected hosted workspace receives the new Employee Library PIN automatically.
