Build a count sheet

Choose Cycle count for selected items or Full inventory for all recorded stock. Set the location, date and your name, then Build Count Sheet. Enter actual physical quantities in count units: zero means none, blank means not counted. Post Count applies the entered balances after confirmation. Open a posted record below to inspect its lines and variance.

Finished correctly: each counted line reflects what is physically present, zeros are entered as zero, and the posted count has been reviewed for unexpected variances.

Choose a location and build a count sheet.

Full inventory requires all locations and every line. Cycle counts may be partial; completed and expected line counts are recorded. Counted by should be the name of the person responsible for this count.

Full counts cover assigned and recorded stock locations. Inspect every physical location; add a row for stock found elsewhere. Unposted entries are not saved. Rebuilding or closing asks before discarding entered quantities.

Purchasing control

Post receiving

Select the item first, then its receiving location. Enter the delivered quantity, cost per count unit and vendor/invoice reference. Check the date and click Post Receiving once. Success clears quantity and reference; verify the result in Item Master or History. Cancel a confirmation to review the form without posting.

Finished correctly: the received quantity, storage location, unit cost, date and source match the delivery or store receipt.

Local purchase? Record it the same way. For Walmart, Sam’s Club, Costco, a grocery store or another local source, type the store name and receipt number in Vendor / invoice. The item remains one inventory item even when you buy it from different places.

Receiving increases the selected location balance. Enter quantity and cost per count unit, not per case. When a new unit cost is received, Inventory Center uses that as the current cost for the remaining stock and records the cost change in History.

Movement control

Transfers, waste and adjustments

Choose the action, item and source/location. Transfers also need a different destination. Enter a positive quantity, date and a meaningful reason identifying the correction or event. Post Movement changes balances immediately. Check the item, location, quantity and reason before posting. If you make a mistake, keep the original History record and post a clearly explained correction.

Finished correctly: the item, location, quantity and reason match what actually happened in the restaurant. Use a transfer when stock physically moved; use waste or an adjustment only for the event that actually occurred.

Transfers move stock between physical locations without changing total on-hand.

Par control

Par & reorder worksheet

Set Par and Reorder point through Item Master → Edit. An active item appears here when stock is at or below its reorder point and below par. Print Current View produces the worksheet; it does not place a supplier order. If nothing appears, check the item settings and current stock.

Finished correctly: par and reorder points reflect how much the restaurant truly needs, and the suggested quantity has been reviewed before anyone places an order.

Suggested order is in count units, returning stock to par. Case pack and yield are reference fields only; orders are not rounded to whole cases and costs are not yield-adjusted.

Help: answers when you need more detail

Normal work should be understandable on each screen. Use Help when you need the fuller explanation, a correction procedure or troubleshooting details.

The complete process

Set the Restaurant Profile → map Locations → build the Item Master → establish starting stock → record receiving, transfers and waste → count and verify → review reorder needs → review History and keep backups. Success means the physical restaurant and Inventory Center tell the same story.

Barcodes: where they come from

A barcode is optional. If the product already has a useful barcode, scan or type that code into the item. If a bulk, local or unlabeled item does not have one, choose Create Inventory Barcode while adding or editing the item. Save the item, then use its Barcode button in Item Master to print a label. Keep one barcode assigned to one inventory item.

Local stores and multiple purchase sources

Items bought from Walmart, Sam’s Club, Costco, grocery stores or other local sources are handled as normal inventory. Do not create a duplicate item just because the source changes. In Item Master, Vendor is the item’s usual source and may be left blank. When receiving a purchase, use Vendor / invoice to record the actual store and receipt or invoice reference. If the same ketchup is bought from Walmart today and a distributor next week, it remains the same ketchup item; each receipt records its own source and current unit cost.

For one-time emergency purchases, receive the quantity into the existing matching item when possible and identify the local source in Vendor / invoice. Only create a new inventory item when the product truly needs to be counted and controlled separately.

Counts and unexpected stock

Pause inventory movements while counting. Full inventory requires all built lines, including zeros. Inspect every location and use Add Count Row for stock found outside an item's assigned locations. Any inventory scope or balance change requires rebuilding. Cycle counts can be partial. Unposted entries are temporary: post before closing, or cancel the discard prompt to continue. A crash or power failure can still lose an unposted sheet.

Correct a mistaken transaction

History is retained rather than deleted. If you received 10 lb but should have received 8, post a negative adjustment of 2 lb at the same location and reference the original receipt. If you transferred stock to the wrong location, transfer it back and then post the correct transfer if the stock is still available. If later activity has changed balances, verify physical stock first and use a documented count.

Quantity corrections do not reverse unit cost. To correct cost, edit the item's Unit cost. This revalues remaining stock and records a cost change. Inventory Center uses latest cost for operational inventory value; it is not FIFO or weighted-average accounting.

Backups and recovery

Create Backup saves the full posted inventory so it can be restored later. Export Items and Export History create reports; they are not restorable backups. Keep dated backup files in a separate safe location. Restore Backup replaces current inventory, so create a current backup first. Unposted count entries are not included in backups.

Save, export and print

Posted inventory changes save in this browser. Missing required names, dates, quantities, costs or movement reasons block the action and tell you what to correct. Print Current View prints the selected tab. Export Items saves all items; Export History saves recorded movement and cost history. Create Backup saves restorable working data. Keep dated backup files outside the browser because clearing site data can remove browser-stored inventory.

When something goes wrong

If saving fails, the operation is rolled back. Keep the page open, read the displayed error, verify the required fields and available browser storage, then retry. Do not clear site data while troubleshooting; create a current backup first whenever the workspace still allows it. If browser storage is blocked or unavailable, use a normal browser window with site storage allowed. For a problem report, include the browser/device, what you clicked, what you expected and what happened.

Restaurant identity

Restaurant Profile

Restaurant name is required before creating locations, items or posting inventory. Other profile fields are optional and identify your printed work. You are finished with this step when the restaurant name is correct and, if needed, the store number/location identifies the right restaurant. Save Profile applies changes; Cancel or × leaves the existing profile unchanged.

Inventory item

Add Item

Choose the unit you physically count, such as lb or bottle, and enter cost for that same unit. Vendor, SKU and barcode are optional. If you buy an item from more than one place, keep one inventory item and use Vendor as its usual source; enter the actual store or supplier on each receipt. For barcodes, scan/type the code already on the product or create an Inventory Center barcode. Starting on hand is only for the first stock you are bringing into the system.

Use the product barcode when it is reliable. For bulk, local or unlabeled items, create an Inventory Center barcode and print a label after saving.
